# 扉

## 本標準について

Thick Client Application Security Verification Standard は、安全なシッククライアントアプリケーションを定義、構築、テスト、検証するために、アーキテクト、開発者、テスト担当者、セキュリティ専門家、ツールベンダー、使用者が使用できる、アプリケーションセキュリティ要件やテストのリストです。
